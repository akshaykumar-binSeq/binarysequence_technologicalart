# Onboarding UI/UX Wireframe

The introduction is optional and must never prevent access to essential content. Treat the dialog as progressive enhancement, not as the only way to reach the site. Provide a clear primary action and a visible skip/dismiss action. Verify focus placement, focus containment, Escape behavior, and focus restoration. At reduced motion, remove non-essential transitions. Exact node IDs and token references are defined in `UI_UX_WIREFRAME.toml`.
