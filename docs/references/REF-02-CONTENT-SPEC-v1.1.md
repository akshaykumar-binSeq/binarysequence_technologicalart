## 2. Seven Invariant Editorial Rules

1. **Rule 1: Truth Now:** Describe capabilities that exist today in production. Never announce future visions as present capabilities.
2. **Rule 2: Complexity Absorption:** Clearly convey that enterprise complexity is absorbed by architecture, never passed to the user.
3. **Rule 3: Eliminate Speculative Guarantees:** Remove claims of "100% bug-free", "unlimited warranty", or "unconditional guarantees".
4. **Rule 4: 5–15 Year Horizon Reality:** State the 3-layer contractual framework (Vital Stewardship, Evolutionary Credits, Architectural Expansion).
5. **Rule 5: Continuity Protocol:** Explicitly state client code ownership, reproducible environments, and escrow terms.
6. **Rule 6: Evidence Before Metrics:** No synthetic vanity metrics; cite reproducible engineering or verifiable operational realities.
7. **Rule 7: Two-Scroll Scannability:** Every screen's primary thesis and value proposition must be fully clear within two scrolls.
